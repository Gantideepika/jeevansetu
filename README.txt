JeevanSetu Maps Glitch Fix

Open JeevanSetu-Maps-Glitch-Fix.html in your browser. This patch stabilizes responsive map sizing, reveals the real map before loading its iframe, and applies a visibility/layout recovery pass when portal panels open or resize.

Real OpenStreetMap tiles and nearby-service lookup still require internet access. Offline overview is schematic and is not a street-level offline map. GPS access depends on browser/device permissions; opening a local HTML file may block GPS in some mobile browsers.

Validation: inline JavaScript syntax and ZIP integrity checked. This does not constitute a live-network test of OpenStreetMap or on-device GPS.
